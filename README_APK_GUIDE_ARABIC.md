# 📱 دليل بناء واستخراج ملف الـ APK الأصلي لتطبيق سهرة ممتعة

تم تجهيز المشروع بالكامل بهيكلية أندرويد الأصلية (**Android Native Project**) وملف ضبط **Capacitor** وسير عمل **GitHub Actions** الآلي لبناء الـ APK تلقائياً.

---

## 🚀 الطريقة الأولى: استخراج الـ APK تلقائياً عبر GitHub Actions (الأسهل بدون تثبيت برامج)

1. **تصدير المشروع إلى GitHub**:
   - من القائمة العلوية أو الإعدادات في AI Studio، اختر **Export to GitHub** (أو حمّل ملف الـ ZIP وارفعه لمستودعك على GitHub).
2. **بدء البناء التلقائي**:
   - توجه إلى تبويب **Actions** داخل مستودع GitHub الخاص بك.
   - ستجد سير عمل باسم **Build Android APK** يعمل تلقائياً بمجرد رفع الكود.
   - يمكنك تشغيله يدوياً بالضغط على **Run workflow**.
3. **تحميل الـ APK**:
   - بعد اكتمال البناء (عادة خلال دقيقتين)، انقر على آخر تشغيل للـ Workflow.
   - ستجد في قسم **Artifacts** في الأسفل ملف جاهز للتحميل المباشر باسم:
     `MovieRoom-Debug-APK` (يحتوي على `app-debug.apk`).
   - ثبّته على أي هاتف أندرويد مباشرة!

---

## 💻 الطريقة الثانية: فتح وبناء الـ APK عبر Android Studio

1. حمّل ملفات المشروع بالكامل (Download ZIP) وفك الضغط.
2. افتح برنامج **Android Studio**.
3. اختر **Open** ثم حدد مجلد `android` الموجود داخل المشروع.
4. انتظر حتى ينتهي Gradle من المزامنة (Sync).
5. من القائمة العلوية:
   - اختر **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
6. بمجرد الانتهاء، ستظهر رسالة تخبرك بمسار الـ APK مع زر **locate** لفتحه مباشرة.

---

## ⚙️ هيكلية الملفات المضمنة:

- **`android/app/src/main/AndroidManifest.xml`**:
  - يحتوي على صلاحيات المايكروفون (RECORD_AUDIO) والكاميرا (CAMERA) للصوت عالي الدقة وتقنية WebRTC.
  - صلاحيات الوسائط، الشبكة والإنترنت، والحفاظ على الشاشة أثناء المشاهدة (WAKE_LOCK).
- **`android/app/src/main/java/com/movieroom/app/MainActivity.java`**:
  - مشغل الـ Native WebView مع تفويض صلاحيات الصوت والفيديو تلقائياً وتفعيل ملء الشاشة.
- **`android/app/build.gradle` & `android/build.gradle`**:
  - إعدادات Gradle 8+ و Java 17 المتوافقة مع أحدث إصدارات أندرويد (Android 14 / API 34).
- **`.github/workflows/build-apk.yml`**:
  - البناء الآلي للـ APK ورفعه كـ Artifact قابل للتنزيل فوراً.
