# مشروع منصة AH - تطبيق أندرويد الأصلي (Android Native Kotlin & Jetpack Compose)

هذا المجلد يحتوي على كود أندرويد الأصلي المتطابق بنسبة 100% مع تطبيق الويب المعتمد لمنصة **AH**.

## الميزات المتطابقة مع نسخة الويب:
1. **اسم التطبيق والشعار**: `AH` مع الشعار الرسمي (أيقونة AH مع النقطة الخضراء للبث المباشر).
2. **الواجهات البصرية وأسلوب العرض**:
   - `LandingScreen`: الواجهة التعريفية مع شعار AH وزر الدخول.
   - `LoginScreen`: تسجيل الدخول، تذكر الحساب، والدخول السريع كضيف.
   - `HomeScreen`: تبويبات الغرف العامة، إنشاء غرفة جديدة، الانضمام السريع برمز، سجل الغرف، والمحتوى المميز.
   - `WatchRoomScreen`: شاشة المشاهدة الجماعية المتزامنة مع مشغل يوتيوب ودعم البث المباشر والدردشة التفاعلية.
3. **مشغل يوتيوب والمزامنة**:
   - دعم كامل لروابط YouTube بمختلف صيغها مع مزامنة التشغيل والإيقاف.
   - إمكانية تغيير رابط الفيديو المباشر داخل الغرفة.
   - دعم الغرف العامة والخاصة المحمية برمز مرور (PIN).

## طريقة البناء والتشغيل:
1. افتح هذا المجلد (`android`) في برنامج **Android Studio**.
2. انتظر ثوانٍ لمزامنة Gradle.
3. اضغط **Run** لتشغيل التطبيق على الهاتف أو المحاكي.
4. أو من خلال **GitHub Actions** عبر تشغيل سير العمل `build-apk.yml`.
